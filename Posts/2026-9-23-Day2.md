## 1.3 Bandwidth and Throughput

Streaming and gaming require a fast and reliable stream of a high amount of bits. The amount of possible data a network can proccess at once is its bandwidth.

- KBPS: thousands
- MBPS: Millions
- GBPS: Billions

Throughput: the measure of the transfer of bits across the media over a period of time. Due to outside factors, throughput never usually reaches the same value as bandwidth.

Could be caused by: Types of data being transmitted, latency or travel time, amount of data being sent.

Throughput doesn't take into account the value or usefullness of the data being transmitted or recieved.

In a network, throughput cannot be faster than the slowest link from two devices trasmitting to eachother. AKA, it cannot be faster as the slowest connection in the network.

# Mod 2: Network Components, Types, and Connections

## 2.1 Clients and Servers

Computers connected to a network that directly participate in network communication are classified at hosts. Hosts can send and revieve messages on a network.

In modern networks, hosts can act as a both a client and server.

Servers are hosts with installed software which enable them to provide information to other hosts on the network.

Clients are hosts that have software that enables them to request and display information obtained from a server.

Example: An email server runs email server software. A client runs its main software such as microsoft outlook in order to access mail stored in the email server.

It is possible for a computer to run both client and server software at the same time. This type is called peer to peer (p2p) network

P2P Network consists of two directly connected computers (connected via wire/wireless). Both computers are able to use P2P to exchange data with eachother, acting as a client or server when needed.

Many pcs can be connected together to build a large P2P network, but it required a network device like a switch to interconnect all computers. 

Pros of P2P:
- Easy Set up
- low complexity
- lower cost (no need for external servers)
- Can be used for simple tasks

Cons of P2P: 
- No centralized Administration
- Not as secure
- Not scalable 
- May cause performance issues due to computers acting as servers and clients at the same time

For businesses, it is usally better to have didicated servers to support service request.

P2P applications allow a device to use P2P. These apps usually require some sort of UI and run a background service.
Some P2P apps use a hybrid system where each peer has to access an index server to find the location of a resource stored on another peer.

A device running a sever software can provide services to one or many clients at the same time. A device can also run multiple server softwares at once, which allows for one device to act as a web, file, and email server.

A device can also run mutliple client software, there must be a client software for every service required. Like a computer that wants to check emails, browse the web, and listen to music at the same time.

## ISP Connectivity Options

ISPs provide the link between home networks and the internet. An ISP can be the local cable provider, landline service provider, cellular network provider, or an independent provider who leases bandwidth on a physical network infastructure of another company.

ISPs typically offer additional services to their subscribers, which may include Email, network storage, and website hosting and automatic backup/security services.

ISPs are connected in a hierarchical manner, ensuring that internet traffic generally takes the shortest path in transmission.

The primary medium that connects the internet is fiber optic cabling. Usually stored underground to interconnect entire cities within continents, they can also be run underwater to connect countries.

The most common way to securely connect to the internet is through a router, as it porvides security and ip addressing to inside hosts.

Fiber optic is too expensive and complex for most users, so many use:

Cables: Data signals are carried through a coaxial cable. Usually highbandwidth and always connected to the internet. Ethernet connection provides its owns separate connection to LAN or host computers.

Digital Subscriber Line (DSL): Required a special high speed modem to provide high bandwith and Continuous Connectivity to the internet. DSL runs over telephone line that is split into 3 lines for voice calls, downloading, and sending/uploading. Quality of the DSL speed depends on the quality of the phone line and distance from you to the central office.

Other ISP Connection Options:

Cellular: Cell phone network to connect to the internet. Limited to the quality of the phone and the cell tower the phone is connected to. Downside is that bandwidth is usually limited and charged for using extra.

Satellite: Good option for businesses that don't have cable or DSL. Require a clear line of sight from the business to the satelite so overhead obstructions block any connectivity. High set up cost along with monthly charges. Provide mobile connectivity like cellular. 

Dial up Telephone: Cheap connectin that uses phone line and modem. Connection requires a call to the ISP. Provides low bandwith, not reccomended for large data usage.

Types of wireless networks
