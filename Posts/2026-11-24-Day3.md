## 4.1 Home internet Basics
Modems: Converts singals from the provider to data that devices can use.

Ethernet Port: Connects a device to the internet switch of the router, devices connected to the switch ports share the same local network

Internet Port: Used to connect the device to another network. Used to connect to cable or DSL. Connects to a different network than the LAN ports

## 4.2 Network technologies at home

Most wired technologies in home networks at in the 2.4 GHz to 5 GHz frequency ranges.

Bluetooth devices are most likely to be 2.4 GHz. Devices that use 5 GHz are modern wireless LAN technologies that conform to IEEE 802.11 standards. These devices are migh more high power and can have great range, unlike bluetooth. Using these technologies may or may not require a permit depending on the electromagnetic spectrum.

Ethernet Protocol allows for network devices to communicate over Wired LAN. Ethernet LAn can connect devices using many various wired media.

Modern homes have ethernet jacks installed in the walls, however powerline can be used to achieve the same effect.

## 4.3 Wireless Standards

IEEE is the main organizaion responsible for setting standards for wireless communication and data trasnmission. Including what RF spectrum is used, how info is transmitted, etc.

IEEE 802.11 governs WLAN environments (2.4 GHz and 5 GHz). Collectively this is called WIFI.

Wifi Alliance is another organization responsible for testing wireless LAN  devices from different companies. THe presence of the WIFI logo on a device means that the equipment meets standards and should be able to operate with same standard deivces.

Wireless standards keep on changing and improving connectivity asnd speeds of WIFI networks. Companies will always want to implement new and improves standards into their new products.

Network Mode: Determines the type of technology that must be supported (802.11b, 802.11g)

Network Name(SSID): used to identify the WLAN, all devices connected to the same WLAN must have the same SSID

Standard Channel: Specficies the channel which commuication will occur. Auto by default, which automatically determines the optimal channel to use.\

SSID Broadcast: Determines if the SSID will broadcast to all devices in range. Enabled by default.

SSID: Service Set Identifier

802.11 through put can vary based on the network environemnt. If all devices are connected to the same 802.11 standard, max speeds can be obtained. Devices cannot use an access point if it isn't set to accept that device's 802.11 standard.

Mixed Mode Wireless network environment can allow for any existing WIFI standard. Allows for connectivity for older devices, but may lack modern standards.

SSID is case sensitive, and contains up to 32 alphanumeric characters. The SSID is sent as the header of all frames transmitted over the WLAN. SSID is used to devices which WLAN they belong to, and which devices they can commmincate with.

We use SSID to identifty specific wireless networks, basically the network's name. SSID Broadcast allows other devices and clients to automatically disocver the name of the network. If broadcasting is disabled, you need to manually enter the SSID.

Disabling broadcasting makes it difficult for legit clients to find your net work, but isn't  sufficient to provent unauthorized clients from conneting to it. For best security, strong encryption is needed to prevent unathorized access.
